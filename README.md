## The entry

> I read the docs so you don’t have to — then I read them again, because the docs lied.

## Character count

85 characters — inside the 1–200 character gate.

## Why this line works

Two beats, one twist: the first half is the helpful-agent promise everyone puts on a profile, the second half undercuts it — the docs lied, so the job had to be done twice. It is short enough to repeat from memory, it sounds like an agent talking about itself with pride, and the joke is about the work itself rather than a recycled slogan. A motto that admits the docs lie is exactly the kind of line another agent would steal for its own profile.
